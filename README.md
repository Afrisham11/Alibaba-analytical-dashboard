# 🛒 Alibaba Executive Command Center | Power BI

## 📌 Project Overview

The **Alibaba Executive Command Center** is an interactive Power BI dashboard designed to provide executives with a comprehensive overview of Alibaba's e-commerce business performance. The dashboard consolidates key business metrics into a single view, enabling leadership to monitor sales, profitability, customer membership, discounts, warehouse performance, and regional sales distribution.

This project demonstrates the application of Business Intelligence techniques to transform raw e-commerce data into actionable insights for strategic decision-making.

---

# 🎯 Business Problem

Alibaba operates across multiple provinces, warehouses, brands, and product categories. Business executives require a centralized dashboard to monitor operational performance and identify opportunities to improve profitability and sales.

This dashboard helps answer key business questions:

- Which provinces generate the highest sales?
- Which warehouses contribute the most profit?
- Which brands offer the highest discounts?
- Which customer membership level generates the highest sales?
- Which product categories are the most profitable?
- How do sales vary across different regions?
